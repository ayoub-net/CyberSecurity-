# Cybersecurity Labs

A collection of practical cybersecurity labs focused on network reconnaissance, vulnerability assessment, penetration testing fundamentals, and defensive security.

## Topics

- Nmap and Network Reconnaissance
- Network Enumeration
- Vulnerability Assessment
- Linux Security
- Web Application Security
- Penetration Testing Fundamentals
- Metasploitable2 Labs
- Active Directory Security
- Security Hardening
- Security Monitoring and Analysis

## Tools and Technologies

- Kali Linux
- Nmap
- Metasploitable2
- Burp Suite
- Wireshark
- Linux Terminal
- VMware Workstation
- PNETLab / GNS3

## Learning Objectives

- Understand common security assessment techniques.
- Practice reconnaissance and enumeration in authorized labs.
- Identify and document security weaknesses.
- Learn basic defensive measures and remediation.
- Develop practical cybersecurity skills.

## Authorization

All security testing is performed in authorized environments, such as personal virtual machines and dedicated training labs.
